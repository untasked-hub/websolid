New to Push/Pull?
  1. Click a top or bottom flat face of the solid — the picked face turns blue.
  2. Type a distance in millimetres. Positive grows the part outward, negative cuts it back.
  3. Press Apply to add the edit to the feature tree, or Cancel to leave the part unchanged.

Extruded parts with flat top/bottom faces only. Distance 0.01–1000 mm, and the part must stay 0.5–2000 mm thick.

    Export preflight

    Blocking checks highlight geometry to review; export is still available below.

    Blocking geometry checks

      Advisory checks

        • STL · binary mesh: whole part geometry. Coordinates are in mm here, but STL stores no unit metadata; set units to millimetres when importing.
        • DXF R12 · sketch: active sketch outline and hole/seat circles only, in mm; it does not include the extruded 3D solid.
        • SVG · drawing: orthographic top, front, and right views include the sheet scale, overall mm bounds, and each view’s mm dimensions. It is a reference preview, not a toleranced manufacturing drawing.
        • CSV · BOM: hole list plus part name, material, volume (mm³), mass (g), and bounding box (mm).
        • JSON · part file: the editable definition only — sketch, extrusion, holes, material, equations, feature history. It contains no mesh and no account state, so it can be handed to another person or opened in a different browser.

        Saving: Save part and the parts library use server-side storage. They are not browser-local saves. If the library is unavailable, use Save file: a .json part file keeps the editable parametric definition and, unlike STL/DXF/SVG/CSV, can be opened again in WebSolid. The “Part file saved” status is tracked only in this page session; after a reload, WebSolid cannot check whether an earlier export still exists on your device.
